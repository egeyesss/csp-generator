# Code of Conduct

## The short version

Be kind. Assume good faith. Critique the code, not the person. Don't make anyone feel unwelcome.

This project follows the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), summarized below.

## Expected behavior

- Be respectful in issues, PRs, reviews, and any other project space.
- Welcome questions from people new to the project.
- Disagree about technical decisions on the merits. Past contributions don't entitle anyone to deference; bad ideas from senior contributors should be pushed back on the same way bad ideas from anyone else would be.
- Give clear, actionable feedback. "This won't work because X" beats "this is wrong."
- Accept that you might be the one who's wrong.

## Unacceptable behavior

Harassment of any kind, personal attacks, discriminatory language or imagery, deliberate intimidation, and sustained disruption of discussion are not tolerated. Neither is publishing other contributors' private information without their permission. The [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) has a more detailed list.

## Scope

This Code of Conduct applies inside all project spaces — the repository, the issue tracker, PRs, code reviews, and any public space where you're representing the project.

## Reporting

If you see behavior that violates this Code, email the maintainer at **egeyesilyurtca@gmail.com**. Reports will be handled confidentially. The maintainer commits to responding within a reasonable window and taking appropriate action — which may include warnings, temporary bans, or permanent removal from the project, depending on severity.

## Enforcement

The maintainer is responsible for enforcement and has the final call. If you're affected by an enforcement decision and believe it was made in error, you can reply to the original report thread to appeal.
